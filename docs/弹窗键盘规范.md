## 1. 目标效果（验收标准）

打开任意含输入的弹窗并聚焦输入框时：

| 项 | 必须 |
|---|---|
| 底页（列表 / `.app-main`） | **完全不动**，不跟键盘一起滑 |
| 遮罩（scrim） | **铺满** bezel，不缩高度、不露底页 |
| 弹窗卡片 | **单独上移**，使输入区落在键盘上方的可视带内 |
| 其它壳层（Tab 占位等） | 不因弹窗改布局高度；键盘态可淡出 Tab，但占位保留 |

一句话：**只动弹窗，不动底页。**

## 2. 强制用法

### 2.1 组件选择

| 场景 | 组件 | 说明 |
|---|---|---|
| 有 `input` / `textarea` / 需要打字 | **`CenterModal`** | 唯一合法带输入弹层 |
| 无输入的确认 / 菜单 | `ActionSheet` | 同样冻结底页；无 lift |
| 短结果 | `useOverlay().toast()` | 不抢焦点 |

**禁止**

- 业务页 `createPortal` 自画 `.modal-overlay`
- 用 `position:fixed` 全屏 div 冒充弹窗
- 聚焦时对输入框 `scrollIntoView`（会拖底页）
- 用 `--vv-height` **缩小遮罩**高度（会露底、闪页）
- 键盘时修改 `--app-height` 或给底页加 translate

### 2.2 业务侧最小写法

```tsx
import { CenterModal } from "@/components/overlay/CenterModal";

<CenterModal open={open} title="标题" onClose={close} footer={...}>
  <input data-autofocus="true" /* 需要打开后自动聚焦时 */ />
  {/* 或其它表单字段，用户点击聚焦亦可 */}
</CenterModal>
```

- 自动聚焦：给目标控件加 `data-autofocus="true"`（由 `CenterModal` 入场后再 `focus({ preventScroll: true })`）
- 不要写 `autoFocus`（会抢在入场/锁滚之前）

### 2.3 结构契约（改 CSS / 组件时勿拆）

```
#anzai-overlay-root.overlay-root
  └── .modal-overlay          ← inset:0 遮罩，永不跟 vv 缩高度
        └── .modal-lift       ← 唯一允许随键盘 translate 的节点
              └── .modal-card ← 入场动画（opacity + transform）
```

## 3. 机制分层（实现真相）

| 层 | 做什么 | 代码 |
|---|---|---|
| 遮罩铺满 | 底页不露出来 | `.modal-overlay { inset: 0 }` |
| 底页冻结 | 列表 / main 不滚、不跟手 | `lockUnderlyingScroll()`；`html[data-modal="1"]` + `[data-anzai-scroll-lock]` |
| Focus 接管 | 禁止 Safari 预滚动 layout | `useIOSFocusGuard`（modal 内预览/真机都开）+ `focus({ preventScroll })` |
| 仅卡片上移 | 输入区到键盘上方 | `--keyboard-inset` ← `useAppViewport`；`html[data-modal="1"] .modal-lift { transform: translateY(-0.5 * inset) }` |
| 壳高稳定 | 不与系统对打 | `--app-height` 键盘时不缩 |

抬升量：约为键盘占位的 **一半**（把原「全屏居中」重放到「键盘上方可视带居中」）。变量封顶在 viewport 测量里完成，业务勿再算一遍。

## 4. 新弹窗 Checklist

合并功能前自检：

- [ ] 使用 `CenterModal`，未新建 portal 弹层  
- [ ] 输入字号 ≥ 16px  
- [ ] 需要自动聚焦时用 `data-autofocus`，不用 `autoFocus`  
- [ ] 未调用 `scrollIntoView` / 未改 `--app-height`  
- [ ] 真机或窄屏：聚焦后**底页静止**、**卡片上移**、输入不被键盘挡住  
- [ ] 关闭弹窗后列表滚位恢复、无底缝  

---

## 5. 无输入弹层

`ActionSheet` / Toast：

- 同样走 overlay root；Sheet 打开时也 `lockUnderlyingScroll`
- **不做** `.modal-lift` 键盘抬升（无输入）
- 不要把带输入的表单塞进 ActionSheet
