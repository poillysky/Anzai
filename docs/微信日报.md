# 微信仓库日报（多用户）

在 **安崽 → 设置 → 微信日报** 配置。每位用户独立通道与时刻，互不影响。

## 流程

1. API 进程内每分钟检查各账号设定时间（北京时间）
2. 对该用户跑仓库分析（档位自选 light / standard / deep）
3. 经该用户的 Server酱 / PushPlus / WxPusher 推送到微信
4. 按用户去重（同日默认一次）

## 设置项

| 项 | 说明 |
|---|---|
| 开启日报 | 本账号是否参与定时 |
| 通道 | Server酱 / PushPlus / WxPusher |
| 密钥 | SendKey / Token / AppToken·SPT（仅存本账号） |
| 时间 | 时、分 + 星期 |
| 分析档位 | 轻量 / 标准 / 深度 |
| 试发 | 测试消息 / 立刻推送 |

## API（需登录）

```http
GET  /api/notify/settings
PUT  /api/notify/settings
POST /api/notify/test
POST /api/notify/run-digest?force=1
```

## 注意

- API 进程需常开，定时才生效
- 正文含「仅供参考，不构成投资建议」
- 密钥存在 `preferences.notify_json`，不进全局 `.env`
