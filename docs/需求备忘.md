## 1. 产品定位

| 项 | 要求 |
|---|---|
| 产品名 | **安崽** |
| 本质 | 个人股票 / ETF **分析助手**（不是交易下单工具） |
| 服务对象 | 本人个人使用；单人本地 / 私有部署 |
| 不做 | 多租户、社交、自动下单、公开展示型产品 |

**核心价值（原文意图）**

1. 为我个人股票提供 **实时分析** 与 **规划**
2. 一眼看清持仓与组合状态
3. 有 **Agent 智能分析助手**，结合持仓与行情做解释与建议

## 2. 市场与数据范围

| 项 | 已确认 |
|---|---|
| 市场 | **A 股**（仓库 / 分析 / 持仓） |
| 品种重心 | 场内 **ETF** 为主 |
| 持仓扩展 | 可含 A 股个股（录入与展示） |
| 黄金 | **股票页「股票\|黄金」**；黄金内 **国内 / 国际 / 门店**。国内：AU9999（上金所，仅查阅）+ 工行/浙商/民生积存金（可入仓，按克）+ 博时/工银瑞信黄金ETF（可入仓）；国际：伦敦金/纽约金；门店：周大福/老凤祥等品牌零售·回收参考（以门店公示为准） |
| 聊天可查 | **港股**报价 / 分时 / 日K（安崽对话）；**不进仓库**、不开标准分析 |
| 不做（当前） | 美股、跨境组合、港股入仓、AU9999/期货入仓（除非日后追加） |

**行情相关要求**

- 准实时 / 盘中可刷新（打开 App 时轮询即可；iOS PWA 后台能力有限）
- 行情经后端代理，前端不直连第三方
- 数据源可切换（适配层）；失败可降级，不可让 App 崩溃
- 界面需标明：行情可能延迟；**非投资建议**

## 3. 体验与交互（PWA / iOS）

用户原话要点：**原生 PWA、iOS 全屏操作模式、流畅、iOS 交互模式、好看美化**

### 3.1 必须达到

- 可「添加到主屏幕」，以 **standalone / 全屏** 接近原生 App
- iOS 安全区正确（刘海、Home Indicator）
- 底部 Tab 导航，手势与滚动流畅
- 视觉要好看、有金融产品质感，不是通用模板脸

### 3.2 信息架构（五 Tab）

1. **仓库** — 个人持仓录入与市值盈亏  
2. **市场** — 自选 / 最新行情数据  
3. **新闻** — 市场要闻 + 持仓相关 + **兴趣**（自定关键词资讯）  
4. **分析** — 日更报告、结构与再平衡建议（原看盘异动延期并入）  
5. **安崽** — Agent 智能对话  

系统参数配置走 API `/admin`，不进 PWA 底栏。详见 [界面设计.md](./界面设计.md) §3。

### 3.3 体验细则

- 布局使用 `100dvh`、安全区 `env(safe-area-inset-*)`
- 盘中刷新间隔可调（如 15–30 秒）；切换 Tab 不丢状态
- 列表与图表要跟得上流畅度（虚拟化 / 按需加载）
- A 股涨跌色：**涨红跌绿**
- 视觉方向：炭黑 / 深墨绿底 + 清晰数字排版；避免紫渐变等 AI 通用风

## 4. 功能需求

### 4.1 持仓与交易记录

- 手动录入：代码、份额、成本
- 支持导入（CSV / 粘贴）与导出备份（后续）
- 计算：市值、盈亏、仓位占比、行业/宽基暴露（分析阶段加强）
- 持仓卡 **约5分短线倾向**：A 股近端动量+量能等；**积存金/AU** 看图结构（近6小时波段高点回撤+斜率+均值位置）→「金价偏跌 / 震荡偏跌」等，更贴分时右侧；**非预测**；`GET /api/market/short-bias`
- **盘口·资金（轻）**：买卖五档（新浪为主）+ 近几日资金流向（东财 fflow，失败回退 AKShare）；持仓详情展示；安崽 Tool `get_depth_flow`；主力=成交额分档，**禁止**「庄家入场」表述；接口 `GET /api/market/depth-flow`。**黄金 ETF**（场内）有日频资金、盘中五档；**积存金（JD）**无交易所盘口/主力分档（场外金价）
- 本地持久化（SQLite）

### 4.2 实时分析与规划

用户原话：**为我个人股票提供实时分析，规划**

- **盘中**：涨跌、偏离成本、组合波动摘要
- **收盘 / 日报告**：收益归因、波动、相关性粗估、集中度
- **规划**：目标仓位模板 vs 当前仓位，给出 **调仓建议**（只建议，不下单）

### 4.2b 分析页多 Agent 委员会（P1）

- **四席**：走势席（分时/K/多周期）∥ 新闻席 → **结构风险席（确定性）** → 辩证席（1～2 回合）→ 首席综合  
- **独立 L0 模型**（`/admin/analysis-llm`，与安崽对话 `/admin/llm` 分开），分席独立 prompt / 独立 completion（非一次扮演四角）；结构风险席不走 LLM  
- **轮次**：仓库固定标准档（无档位选择）；个股可选轻量 / 标准 / 深度  
- **日期**：证据按上海日历标「今日 / 非今日」；跨日未开盘时今日涨跌归零，昨盘涨跌单列，禁止把昨收说成今日  
- **准确度**：先冻结构事实（头部仓位 / 持仓行情相对上证 / **组合今日盈亏% vs 上证** / 新闻新旧）再开会；辩证 `open_questions` 首席必须回应；watch 带证据引用。参考 [TradingAgents](https://github.com/TauricResearch/TradingAgents) 的「分席 + 辩论 + 风控」思路，**不**引入其整套交易公司 / LangGraph / 美股工具链  

- **证据**：报价 + 指数 + 分时（昨收/今开/最新）+ **盘口资金**（主力净流入/买1卖1；非交易时段无五档）+ 日K 区间涨跌 + 条件宏观 + 新闻；持仓分列今日盈亏与行情；禁止编造未纳入指标；主力≠庄家  
- **交互**：SSE 进度；报告展示各席 / 辩证 / 终裁；LLM 失败回退模板  
- **回归**：`apps/api/scripts/verify-analysis-committee.py`（结构事实 / 风险席 / 头部注入 / 日期字段）

### 4.3 Agent 智能助手（安崽）

用户原话：**有 agent 智能分析助手**

- 流式对话（SSE）；**多会话**：对话记录列表、关闭对话、新开对话；消息按 `conversation_id` 落库；设置里可清空全部
- **口吻**：心里专业、嘴上白话（少术语）；像微信，不播报、不推销；数字禁止 `**加粗**`，嵌进口语句子；**禁研报体**（小标题 / 分点操作清单 / 行情看板复述）
- **硬约束**：数字只来自 Tool / 上下文，禁止瞎编（如未查的 DXY/美债/COMEX）；**可给倾向性买卖/调仓建议**（观望、轻仓、宜减不宜加等），禁止硬指令（立刻全仓/必须卖掉）、禁止承诺收益、不假装代下单

**已落地 Tools**：`get_indices` / `get_quote` / `get_intraday` / `get_kline` / `get_sector` / `get_macro`（黄金/白银/原油/铜/铁矿/螺纹/豆粕/天然气/在岸·离岸人民币；`overview` 看板） / `get_portfolio`（`day_pnl`/`quote_chg` 分列） / `draft_rebalance_plan` / `get_news`（市场版块 board + 持仓 + 关键词；条目带今日/N天前） / `search_symbol` / `get_analysis_snapshot` / `get_leaders` / `search_knowledge`（经验库）；问代码或名称时自动深取；宏观主题预取中文关键词新闻；榜单/报告按需预取。

**经验知识库**：内容以 Postgres 为准（白名单人工录入）。后台 **知识库**（`/admin/knowledge`）可视化增删改/重嵌；**向量模型**（`/admin/embedding`）配库地址与 Embedding API。Markdown（`data/knowledge/*.md`）仅作导入/补种，不再因 MD 缺失删除库内卡。未配库或失败时回退本地索引/关键词。返回标 `【经验库·非实时】`，不得当行情。

**场景包（`agent_scene`）**：按本轮意图投喂，不每轮固定长模板。
- 场景：`chat` / `macro` / `market` / `stock` / `portfolio` / `leaders` / `analysis` / `news`
- 人设薄、固定；仓库 / 分析师 Skill / 场景说明按场景开关；仓库上下文可夹带「上次分析结论」一句
- 例：只问黄金 → 只带宏观+日历，不带仓库；问仓位 → 才带仓库摘要
- **动态篇幅**：`max_tokens` + 篇幅提示按场景/问句长短调整（闲聊短、个股深挖较长），不每轮锁死同一字数

**体验（已落地）**
- 持仓口径：silent / tool 文案分清 `day_pnl`（今日盈亏）与 `quote_chg`（行情涨跌）；纯指数不问仓
- 预取边界：收紧仓位/经验触发词；账户体感才拉仓库，大盘点位只拉指数
- 结果扫读：SSE `card`（持仓/调仓，会话内展示、不落库）；前端建议 chips + 工具步骤条 + 结果卡
- 分析并行：仅明确口令才 `start_analysis`（仓库巡检，或「帮我分析XX」个股标准档）；进行中有话术；完成后带上结论

**待加（按价值排序，触发再做）**

| 能力 | 说明 |
|---|---|
| 结果卡持久化 | 刷新后仍显示结构化卡（需消息表扩列） |
| 财务摘要 Tool | 营收/净利/估值关键项（有可靠源再接） |
| 资金/龙虎榜（轻） | 五档+资金流向已落地（`depth-flow` / `get_depth_flow`）；龙虎榜摘要仍待做 |
| 自选对比 | 持仓 vs 自选，白话对比 |
| 风险偏好设定 | 设置页写入，注入提示词 |

**人性化（冻结）**：称呼稀薄；禁四段套路；术语译成人话；工具返回文案本身偏口语。

## 5. 技术选型（已确认）

| 层 | 选型 | 备注 |
|---|---|---|
| 前端 | Next.js（App Router）+ TypeScript + Tailwind | 纯 PWA 壳与 UI |
| 后端 | **FastAPI**（用户确认合适） | 持仓 / 行情 / 分析 / Agent 全走后端 |
| LLM | OpenAI **兼容** API | OpenAI / DeepSeek / 通义等，env 配置 |
| 数据库 | SQLite + SQLAlchemy | 个人零运维 |
| 行情 | 适配器（现用新浪等公开源，可换 akshare 等） | 缓存 + 限流意识 |
| 编排 | 本地双进程；可选 docker-compose | |

**分工铁律**

- Next.js **不做**业务 API
- 密钥（LLM、口令等）只放后端 / env，不进前端明文仓库习惯用法

**鉴权**

- 本机 / 私有访问口令（`APP_PASSWORD` / `X-App-Password`），非完整账号体系

## 6. 合规与边界

- 显著位置标注：**分析与建议不构成投资建议**
- 不提供自动交易、不承诺收益
- 公开行情源可能限流或不稳定 → 必须可降级、可换源
- iOS Safari PWA：后台刷新与 Push 受限 → 「实时」定义为打开 App 时的准实时

## 7. 成功标准（MVP）

1. iPhone 加到主屏幕后全屏可用，安全区与底部导航正确  
2. 可录入持仓并看到当日盈亏与仓位结构（数据来自 FastAPI）  
3. 能生成一页可读的组合分析 / 调仓建议  
4. Agent 能结合真实持仓回答，并给出可核对的数据引用
