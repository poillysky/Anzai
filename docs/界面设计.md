## 1. 好看的 UI 图标从哪里来

### 1.1 结论（安崽采用）

| 用途 | 来源 | 理由 |
|---|---|---|
| **全部 UI 图标** | **[Lucide](https://lucide.dev/)**（唯一）+ `lucide-react` | **禁止手绘 SVG 图标**；统一经 `@/components/ui/icons` 导出 |
| **视觉对照（不直接嵌字体）** | **[SF Symbols](https://developer.apple.com/sf-symbols/)** App 浏览 | 定「iOS 原生像不像」的参照；**不要**把 SF 字体文件塞进 Web（授权面向 Apple 平台 App） |
| **备选线标** | [Phosphor](https://phosphoricons.com/)（Regular）或 [Heroicons](https://heroicons.com/) Outline | Lucide 缺某语义时补；保持同一描边粗细 |
| **聚合检索** | [Iconify](https://icon-sets.iconify.design/)（搜 lucide / phosphor） | 快速找同名图标，导出 SVG |
| **PWA 应用图标 / Splash** | **自制品牌图**（已有 `public/icons`） | 不能用通用 icon pack 当 App 图标 |

**不采用：** emoji 当 Tab 图标；彩色多风格混搭；IconFont 一大包全站引入（难 tree-shake、难跟 `currentColor`）。

### 1.2 使用规范（实现时遵守）

1. **尺寸**：Tab / 工具栏 **24×24**；列表行旁 **20×20**；大空态插图可 48–64。  
2. **描边**：约 **1.75–2px**（与现 Tab 的 `strokeWidth="1.8"` 对齐）。  
3. **颜色**：一律 `currentColor`，由父级控制（未选 mute / 选中 brand）。  
4. **落盘方式**：一律 `import { X } from "@/components/ui/icons"`（内部 re-export lucide-react，按需 tree-shake）。  
5. **禁止**在 `features/` / `layout/` 内手写 `<svg>` 图标路径。  
6. **选中态**：靠颜色 + `strokeWidth` 略加粗 + `tab-icon-pop`，不用 filled 第二套。

### 1.3 Tab 已落地（Lucide · 五 Tab）

| Tab | Lucide | 说明 |
|---|---|---|
| 仓库 | `Warehouse` | 个人持仓配置 |
| 市场 | `ChartColumn` | 最新行情/自选 |
| 新闻 | `Newspaper` | 市场要闻 + 持仓相关 |
| 分析 | `PieChart` | 结构/报告（原看盘异动后续并入） |
| 安崽 | `Bot` | 智能对话 |

### 1.4 版权与态度

- Lucide（ISC，等同可商用）、Tabler / Phosphor / Heroicons（MIT）：可商用。  
- SF Symbols：作**设计参考**；安崽默认 **不依赖 SF 字体文件**。  
- 第三方 PNG 图标站（付费包）：非必要不买；线标 SVG 足够。  
- **禁止**：同一屏混用两套描边语言（例如 Lucide + Material 实心混搭）。

### 1.5 优秀图标库对照（调研补充）

有，而且一线免费库已经很够用。按「适不适合安崽 iOS 深色金融壳」排序：

| 库 | 体量 / 许可 | 风格 | 适合安崽？ | 链接 |
|---|---|---|---|---|
| **Lucide** | ~1900+ / ISC | 细描边、极简，Feather 系进化 | **首选**：与现 Tab SVG、SF 气质最近 | [lucide.dev](https://lucide.dev/) |
| **Tabler Icons** | 6100+ / MIT | 24×24、2px 描边，有 outline+filled | **次选**：Lucide 缺语义时补；量最大 | [tabler.io/icons](https://tabler.io/icons) |
| **Phosphor** | 多字重 / MIT | Thin→Bold + Duotone | 要「粗细层级」时用 Regular；勿上 Duotone 炫 | [phosphoricons.com](https://phosphoricons.com/) |
| **Heroicons** | ~300+ / MIT | Tailwind 团队，Outline/Solid | 可用，偏 Web Admin；金融语义略少 | [heroicons.com](https://heroicons.com/) |
| **SF Symbols** | Apple | iOS 原生标准 | **只对照，不进包** | [developer.apple.com/sf-symbols](https://developer.apple.com/sf-symbols/) |
| **Iconoir** | ~1500+ | 优雅线标 | 备选审美，非默认 | [iconoir.com](https://iconoir.com/) |
| **Hugeicons** | 免费子集大 | 多风格 | 易风格漂移，**不作为主库** | [hugeicons.com](https://hugeicons.com/) |
| Material / Font Awesome | 大 | Material / 品牌杂 | **不采用**：气质偏 Android/站点，难统一 | — |

**检索入口（不绑定单一库）：** [Iconify](https://icon-sets.iconify.design/) · [IconSearch](https://iconsearch.info/)

**安崽冻结决策：**

1. 主库 = **Lucide**  
2. 缺图标 = 同屏只允许再从 **Tabler Outline** 抽一只（描边对齐 1.8–2px）  
3. 字重变化需求出现前，不上 Phosphor 多字重  
4. 仍不引入 IconFont 整包 / emoji Tab

## 2. 页面架构设计怎么参考（本阶段不做具体内容）

### 2.1 原则

页面架构 = **信息层级 + 区块骨架 + 导航关系**，不是文案、不是真实数据、不是图表样式细节。

参考时只回答三件事：

1. **这一屏首要看什么？**（英雄区是什么）  
2. **往下滚依次是什么区块？**（最多 4–5 块）  
3. **从这屏能去哪？**（Tab / 推入子页 / 弹层）

### 2.2 推荐参考对象（按 Tab）

| 页面 | 主要参考「架构」 | 参考时看什么 | 明确不抄 |
|---|---|---|---|
| 持仓 | Delta / FolioX 总览；券商持仓页只看「总资产→列表」 | 顶数字区高度占比、列表行信息列 | 交易按钮、理财货架 |
| 市场 | 雪球/系统「自选」轻量列表 | 搜索入口位置、行：名+价+涨跌 | 多指数、热力图、资讯流 |
| 新闻 | 东财快讯 / 券商资讯流 | 分段：要闻 vs 持仓相关；行：标题+时间 | 社区 Feed、内嵌浏览器 |
| 分析 | Generali 式「分段报告」；雪球「观点卡」结构 | 结论→结构→建议 三段 | 社区 Feed |
| 安崽 | ChatGPT 输入区布局 + 金融 Agent「结果卡」坑位 | 顶：建议 chips；中：消息流；底：输入 | 纯营销落地页 |

详细产品对比见 [UI调研.md](./UI调研.md)。

### 2.3 参考工作流（以后每次改架构都走一遍）

```text
1. 打开 1～2 个参考 App / 截图
2. 只画「灰块线框」：英雄区 / 列表 / 底栏 / 弹层入口（可用纸面或任意白板）
3. 写入本文 §3「页面骨架」：区块名 + 职责一句话（仍无文案）
4. 对照 iOS全屏设计：安全区、Tab 文档流、Modal vs Sheet
5. 通过后再进视觉（间距、字号）；最后才填内容
```

### 2.4 页面类型（壳已支持）

| 类型 | 何时用 | 架构要点 |
|---|---|---|
| **Tab 根页** | 五 Tab | 有底栏；内容可滚动；TabCache 保活 |
| **推入子页** | 持仓详情等（后期） | 藏底栏；左上返回 |
| **居中 Modal** | 表单（加持仓等） | 有输入；**必须** `CenterModal`（[弹窗键盘规范.md](./弹窗键盘规范.md)） |
| **Action Sheet** | 删除/确认 | 无输入；冻底页 |
| **Toast** | 短结果 | 不占架构层 |

### 2.5 本阶段交付物定义

| 要 | 不要 |
|---|---|
| 每 Tab 的区块列表（名称 + 一句职责） | 具体数字、文案、假数据排版 |
| 全局导航图（Tab ↔ 弹层） | 高保真视觉稿（可后补） |
| 图标来源与组件落点 | 立刻换完全部图标 |

## 3. 页面骨架（五 Tab）

> 2026-08-05 起：**五 Tab**。你方四点 + 补「分析」。区块内仍可不写业务正文。

### 3.0 五 Tab 设计结论

| Tab | 路由 | 一句话职责 | 不做什么 |
|---|---|---|---|
| **仓库** | `/` | **默认打开页**。个人持仓「仓库」配置：录入/删改、市值盈亏 | 不做全市场浏览 |
| **市场** | `/market` | 市场最新相关数据：指数分时、榜单、搜索 | 不做资讯阅读 |
| **新闻** | `/news` | **资讯**：市场要闻 + 持仓相关快讯（外链原文） | 不做盘中异动盯盘 |
| **分析** | `/analysis` | 组合结构、收益归因、再平衡建议卡；**延期**：原看盘异动/提醒并入此处 | 不做实时聊天 |
| **安崽** | `/agent` | 智能对话助手：结合持仓/行情的问答与草案 | 不做原生交易下单 |

**为何第五个是「分析」而不是「设置」：**  
「个人仓库配置」已落在 **仓库** Tab；设置类（密码、LLM）走独立 **`/admin`**，不进 PWA 底栏。  
「新闻」承接阅读；行情列表在「市场」。原「看盘」工作台能力 **延期并入分析**，不占底栏。  
「分析」承接收盘后/深度决策，与安崽（对话）分工。

底栏文案一律 **两字**，适配 5 列密度。  
**冷启动 / 主屏幕图标：** 固定进入 **仓库**（`/`，`manifest.start_url` 同为 `/`）。

### 3.1 全局导航

```text
[仓库] [市场] [新闻] [分析] [安崽]   ← TabBar（5 列，仅变色）
        │
        ├─ CenterModal（表单）
        ├─ ActionSheet（确认）
        └─ Toast（结果）
```

### 3.2 仓库 `/`（个人持股仓管）

| 顺序 | 区块 ID | 职责 |
|---|---|---|
| 1 | `portfolio-hero` | 资产卡：超大总市值；配对今日额/涨跌幅胶囊；集中度环；三枚 KPI（选中石墨提亮） |
| 2 | `portfolio-sort` | 市值 / 今日 / 累计 / 占比（石墨选中，对齐市场指数 Tab） |
| 3 | `portfolio-holdings` | 同代码合并卡片；实心涨跌胶囊；底占比条 |

对标雪球等：信息密度优先。点行支持 **补仓 / 减仓 / 空仓 / 改成本**。圆环可点开仓位说明。约 **15 秒**轮询。

### 3.3 市场 `/market`

| 顺序 | 区块 ID | 职责 |
|---|---|---|
| 1 | `market-session` | 开盘状态条（交易中/午休/已收盘等） |
| 2 | `market-index` | 大号指数价 + 涨跌副标 + 实心涨跌幅胶囊；价位气泡；分时（右轴刻度、虚线均价、末端价泡）；胶囊五指数 Tab（附涨跌%） |
| 3 | `market-search` | 圆角搜索条；有词时列表切结果，榜 Tab 暂隐 |
| 4 | `market-board-tabs` | 涨幅 / 跌幅 / 成交 / 换手 / ETF（搜索中隐藏） |
| 5 | `market-leaders` | 金/银/铜名次章 + 实心涨跌胶囊；点行开详情（迷你分时 + 加入仓库） |

接口：`/api/market/indices`；`/session`；`/intraday`（支持 symbol）；`/leaders?kind=up\|down\|amount\|turnover\|etf`；`/search?q=`。

**市场范围：** 以 **沪深 A 股 / ETF** 为主（榜单、分时、入仓）；港/美指数 Tab **默认相关 ETF**；外盘个股搜索可查阅、不入仓。

体验：收盘/失败不装「实时」；指数 Tile 带涨跌%；成交/换手附涨跌；详情分时失败有空态。

### 3.4 新闻 `/news`

| 顺序 | 区块 ID | 职责 |
|---|---|---|
| 1 | `news-seg` | 市场 / 持仓 / 兴趣 石墨三分段 |
| 2 | `news-boards` | 市场下横向板块轨：要闻 / 科技 / 农业 / 汽车 / 地产 / 能源 / 产经 / 金融 / 公司 |
| 3 | `news-interest-bar` | 兴趣下：已选关键词芯片 + 编辑（CenterModal 增删，最多 8） |
| 4 | `news-feed` | inset 列表：标题 + 来源·时间；点行应用内阅读弹窗 |

接口：`GET /api/news/boards`；`GET /api/news/market?board=`（默认 100 条；要闻合并东财快讯+新浪+同花顺；栏目保留 mediaName）；`GET /api/news/holdings`；`GET/POST/DELETE /api/news/interests`；`GET /api/news/interests/feed`；`GET /api/news/article?id=`。无持仓 / 无兴趣词时空态引导。`/watch` 重定向至 `/news`。

### 3.5 分析 `/analysis`

| 顺序 | 区块 ID | 职责 |
|---|---|---|
| 1 | `analysis-verdict` | 一句话结论 |
| 2 | `analysis-structure` | 仓位结构 |
| 3 | `analysis-actions` | 再平衡建议卡 |
| 4 | `disclaimer` | 弱提示 |

**延期：** 原看盘「指数快览 / 持仓异动 / 提醒」并入本 Tab，触发再做。

### 3.6 安崽 `/agent`

| 顺序 | 区块 ID | 职责 |
|---|---|---|
| 0 | `agent-nav` | 标题「安崽」+ **设置**齿轮（身份仅在设置内） |
| 1 | `agent-thread` | 气泡对话；SSE 流式；气泡内可显示 `agent-tool-note`（查指数/持仓等进度） |
| 2 | `agent-composer` | 输入区 |
| — | `agent-settings` | Push：**全站账号入口**（改密 / 退出）· 身份设定（进设置藏 TabBar）；仓库页不再单独放账号按钮 |

身份存 `preferences.identity_*`；**全站一套**对话预设；选身份只注入【关系】提示词。对话 `POST /api/agent/chat`（SSE）：精简上下文 + **Tools 按需**（`get_indices` / `get_quote` / `get_portfolio` / `get_news`）；事件含 `tool_start` / `tool_result` / `tool_status` / `token`。消息按用户落库 `agent_messages`。LLM / 预设参数仍在 API `/admin`，不进 PWA。

## 5. 美术风格：为何显「单一」+ 网上优秀方案

### 5.1 现状诊断（单一从哪来）

当前实现接近 **纯 iOS Dark 灰阶三层**（`#000` / `#1c1c1e` / `#2c2c2e`）+ 系统蓝品牌色 + 红绿涨跌。工程上正确，但观感问题是：

| 问题 | 表现 |
|---|---|
| 色相过少 | 整屏几乎只有灰 + 蓝点缀，缺「气氛色」 |
| 深度靠不住 | 暗色下阴影几乎看不见，层差不够时像一块平涂 |
| 材质单一 | 列表/面板同一种实心灰块，无英雄区与列表区的材质对比 |
| 光感缺失 | 无环境光、无顶卡高光、无微纹理 → 易显「模板黑」 |

行业共识（Skins Factory 等）：暗色 UI 的层次要靠 **表面明度级差 + 边线**，不是靠大阴影；纯炭黑容易「像关了灯」，不如带一点色相的深底。

### 5.2 网上可参考的优秀方向（筛过，适合个人金融助手）

下列方案来自公开案例 / 设计系统文章，**已剔除**紫霓虹 AI 风、全站毛玻璃、杂志纯黑白（会伤涨跌语义）。

| 方案代号 | 代表参考 | 核心手法 | 气质 | 适配安崽 |
|---|---|---|---|---|
| **A. 午夜海军 + 英雄渐变卡** | [Midnight Banking](https://designmd.ai/nswamy14/midnight-banking-dashboard) | 底用深蓝黑；**仅总资产卡**用柔和渐变；列表仍 tonal 面板 | 高端银行感 | ★★★★☆ 英雄跳一档，不伤数据区 |
| **B. 石墨精密仪器** | [Keel / Graphite Citrine](https://sleek.design/templates/fintech-app) | 近黑石墨底；**inset 色阶面板 + 发丝分割线**；无浮卡阴影；数字等宽；单点强调色 | 冷静、工具感 | ★★★★★ 最贴「分析助手」 |
| **C. 克制玻璃（点状）** | Apple 系 / [Glass 实践文](https://uxpilot.ai/blogs/glassmorphism-ui)；[优设·金融材质](https://www.uisdc.com/finance-ui) | **只**给英雄卡或 Tab/弹层加轻 blur + 浅描边；背后需有色斑才显玻璃 | 通透、现代 | ★★★★☆ PWA 慎用，仅 1～2 处 |
| **D. 雪球式清透专业** | [雪球 14.0 视觉升级](https://geekdaxue.co/read/xiaohuli-gh2vp@bgui/oiqadw) | 色/形/质/构统一；卡片种类收敛；质感偏扁平+轻水晶 | 国内用户熟悉 | ★★★☆☆ 借「收敛卡片种类」 |
| **E. 金融 Surface 四级** | 即时设计金融深色教程；openInvest design system | 黑底叠不同透明度白 → 4 级表面；描边分割；红绿只服务涨跌 | 规范、可落地 | ★★★★★ 与现 token 最顺接 |

### 5.3 已拍板：① 石墨精密

**决策日期：2026-08-05** — 选用 **① 石墨精密（偏 B+E）**。

落地原则：

1. 底色略带石墨色相，避免死黑 `#000`  
2. **四级表面**：base → grouped → elevated → overlay + 发丝边线  
3. 英雄区与列表材质对比：英雄用 elevated + 顶沿微高光；列表用 inset grouped（无浮阴影）  
4. 顶区极淡品牌蓝环境光（≤5%）  
5. **不上**整页玻璃 / 英雄大渐变 / 第三装饰色  
6. 数字 `tabular-nums`；涨跌色 + 符号（`+` / `↑↓`）

## 8. 信息密度与图标排布（对标支付宝）

### 8.1 问题

预览版字号/留白偏大（页标题 28、英雄数字 34、列表行 padding 偏松），一屏信息量不足。应对标 **支付宝式「小而清、密而不挤」**，而不是营销落地页大字。

### 8.2 调研要点

| 来源 | 可借 |
|---|---|
| [支付宝线上字体规范（优设）](https://www.uisdc.com/alipay-design-specificatio-online-font) | 字号以 2 为进制；辅助说明可到较小级；大金额才用特大号 |
| [支付宝版式规范（优设）](https://www.uisdc.com/alipay-design-specificatio-format) | 间距 **4 的倍数**；卡片间距约 16、区块更紧凑 |
| [AntUI / 支付宝](https://antui.alipay.com/9.9.0/docs/index.html) | 常用 **12 / 13 / 14 / 16 / 17**；列表带图标约 **21×21** |
| Ant Design Mobile RN | `list_item_height` ≈ **44**；Tab 高 ≈ 50；正文偏 15–17 |

支付宝首页特征（观察级）：

- Tab 图标约 **22**，文案 **10**，不抢内容区  
- 列表主文案 ≈ **15**，辅文案 **11–12**  
- 页内标题多为 **17 medium**，很少整页 28+ 大标题  
- 资产数字突出但控制在一屏「英雄区不过半屏」  

### 8.3 安崽已落地密度 Token（`globals.css`）

| Token | 值 | 用途 |
|---|---|---|
| `--fs-caption` | 11 | 辅文、列表 meta |
| `--fs-meta` | 12 | 副标题、chip 文案 |
| `--fs-body` | 14 | 盈亏数字、气泡 |
| `--fs-list` | 15 | 列表主标题、按钮 |
| `--fs-title` | 17 | 页标题（非 28） |
| `--fs-hero` | 26 | 总市值（非 34） |
| `--icon-tab` / `ICON_SIZE_TAB` | 22 | 底栏图标 |
| `--icon-inline` | 16 | 按钮内图标 |
| `--list-row-pad-y/x` | 10 / 12 | 列表行内边距 |
| `--page-pad-x/top` | 12 / 8 | 页边距 |
| `--space-1…4` | 4 / 8 / 12 / 16 | 间距阶梯 |

约束：真实输入框字号仍 ≥ **16**（防 iOS 缩放）；可点行 `min-height` 保持 **44**。

### 8.4 排布原则（继续遵守）

1. **标题矮、列表密**：页标题 17；内容靠列表堆叠  
2. **图标服务文字**：Tab 22、行内 13–16，空态 ≤24，禁止 32+ 装饰大标  
3. **英雄区矮**：总市值一行 + 盈亏一行 + meta 三列，总高度宜控制在首屏上半偏小  
4. **间距用 4 栅格**：区块间距优先 8，少用 16+
