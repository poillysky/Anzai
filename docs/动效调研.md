## 1. 结论（先看这个）

优秀移动 Web / iOS 壳产品的动效不是「更炫」，而是：

1. **每段动画有工作**（反馈 / 连续性 / 层级），无工作则删  
2. **时长分层**：微交互 100–200ms · 组件 200–300ms · 页面 ≤500ms  
3. **只动画 `opacity` + `transform`**（compositor），禁止靠 `height/top/margin` 做过渡  
4. **缓动有语义**：入场 ease-out · 离场 ease-in · 线性仅 loader  
5. **系统感弹簧**：Apple 建议默认 **bounce≈0**（smooth）；弹跳留给手势  
6. **根级尊重 `prefers-reduced-motion`**  
7. **常规 UI 用 CSS 令牌即可**；不为一层 fade 引入 Framer Motion  

本站采用上表，**不引入动画库**；弹层与键盘跟随已按「一段式」优化。

## 3. 优秀方案 → 本站令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `--motion-fast` | 120ms | 按下、颜色、Tab |
| `--motion-base` | 180ms | 次级态、指示 |
| `--motion-enter` | 260ms | Modal / Sheet / Toast / 面板入场 |
| `--motion-exit` | 200ms | 离场（比入场快 ~25%） |
| `--motion-page` | 320ms | 罕用：整页语义转场上限内 |
| `--ease-enter` | `cubic-bezier(0.22, 1, 0.36, 1)` | 入场（iOS 式快速起步、柔和落地） |
| `--ease-exit` | `cubic-bezier(0.4, 0, 1, 1)` | 离场 |
| `--ease-standard` | `cubic-bezier(0.4, 0, 0.2, 1)` | 同元素两态切换 |
| `--ease-spring` | `cubic-bezier(0.2, 1.2, 0.3, 1)` | **仅**按压微弹；弹层禁用 |

兼容别名：`--ease-out` → 同 `--ease-enter`（旧引用不炸）。

## 4. 组件动效契约

| 组件 | 入场 | 禁区 |
|---|---|---|
| `CenterModal` | opacity + translateY(8→0) + 极轻 scale；遮罩铺满；居中；`lockUnderlyingScroll` 冻底页 | 勿跟 live vv 改位置；勿在 focus 时 scrollIntoView |
| `ActionSheet` | translateY(100%→0)，同令牌 | 勿同时闪多块装饰 |
| Toast | scale + 短位移，≤ `--motion-enter` | 勿超过 320ms |
| Tab / 行按压 | `--motion-fast` + 可选极轻 spring | 无指示条弹跳 |
| Loader | `linear` 无限转 | — |

键盘：弹层几何跟 `visualViewport` 连续变化 = 与系统键盘同一段运动；`data-autofocus` 等入场后再聚焦。

## 5. 无障碍

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

重型装饰动效（若以后有）须额外 `matchMedia` 跳过挂载，不能只靠改 duration。

- 不做全站 View Transition 共享元素大片  
- 不做 scroll parallax / hero 缩放秀
