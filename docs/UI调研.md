# 安崽ETF — 前端 UI 市场调研与最佳实现

> 针对：**个人 A 股 / 场内 ETF 分析助手**（非交易下单）+ **iOS standalone PWA** + 四 Tab（持仓 / 市场 / 分析 / 安崽）。  
> 目标：对齐行业优秀产品的信息架构与视觉效果，同时贴合已落地的壳层与交互规范。  
> 日期：2026-08-05  
> 相关：[iOS全屏设计.md](./iOS全屏设计.md) · [交互基础规范.md](./交互基础规范.md) · [架构.md](./架构.md) · **落地决策累计 → [界面设计.md](./界面设计.md)**

## 1. 结论先看（适合你的「最好」）

对安崽来说，**最好的 UI 不是券商 App 的密集行情墙，也不是加密货币炫光仪表盘**，而是：

> **「一眼总资产 + 今日盈亏」→「可扫的持仓行」→「可对话的分析」**  
> 视觉：**iOS 深色分组背景 + A 股红涨绿跌 + 数字等宽对齐**  
> 动效：**短、稳、有触感**（已有令牌），不为炫技加 glow / 毛玻璃堆叠

业界验证过的标杆方向：

| 产品 | 最值得借 |
|---|---|
| **Delta / Stock Events** | 手机端「一眼总览」；日常打开 10 秒看完 |
| **FolioX** | 隐私向、手动持仓、A 股友好、haptic + 简洁 Dashboard |
| **Generali 投资 App 改版** | data-first；减少红底噪音；深色大卡承载核心数字 |
| **雪球（持仓陪伴）** | 「主理人说 / 观点档位」→ 可映射到 **安崽建议卡** |
| **Robinhood-AI / VYNN 类** | Agent：**流式回复 + Tool 进度 + 结构化结果卡**（不是纯气泡） |

你们已有的壳（standalone、safe-area、Tab 保活、Modal/Sheet）在 PWA 赛道 **已经超过多数开源脚手架**；缺口主要在 **持仓页信息层级** 与 **分析/Agent 的结构化呈现**。

## 2. 产品 UI 定位（决定一切取舍）

| 维度 | 安崽 | 不要学成 |
|---|---|---|
| 用户 | 单人自己 | 多账户 / 投顾工作台 |
| 场景 | 盘中瞄一眼 + 收盘看建议 | 专业交易 / Level-2 |
| 核心 Tab | 持仓是首页 | 行情首页堆指数 |
| Agent | 结合真实持仓解释 | 通用 ChatGPT 皮肤 |
| 合规语气 | 免责声明常驻但不抢戏 | 营销 Banner / 理财货架 |

**一句话人设：** 冷静的个人持仓助手，不是券商交易终端，也不是社区。

## 3. 视觉体系：最佳实现（对齐现有 token）

当前 `globals.css` 已正确采用 **iOS Dark HIG 语义色** + **A 股涨跌**（`--up: #ff453a` / `--down: #32d74b`）。继续强化，不要换赛道。

### 3.1 表面层级（金融 Dark 必备 3 层）

| 层 | Token | 用途 |
|---|---|---|
| Base | `--bg` `#000` | 全屏底、状态栏下铺色 |
| Grouped | `--bg-grouped` `#1c1c1e` | 分区列表底 |
| Elevated | `--bg-elevated` `#2c2c2e` | 卡片 / 行按下 / 浮层 |

行业共识：只有「黑底+白字」会显平；**第三层 elevated** 才有「原生 App」厚度（Finnuvora / HIG Dark）。

### 3.2 数字与涨跌（效果差异最大）

| 规则 | 做法 |
|---|---|
| 等宽数字 | `font-variant-numeric: tabular-nums`（市值、涨跌、占比对齐） |
| 涨跌不只靠色 | 色 + `↑/↓` 或 `+/-`（色觉友好，Trading App 设计指南强调） |
| 大数字层级 | 总市值 **28–34px semibold**；日盈亏次一级；列表价 15–17px |
| 品牌色克制 | `--brand` 仅用于可点主操作 / Tab 选中，**不染色涨跌** |

### 3.3 建议「效果」白名单（适合 iOS PWA）

| 效果 | 推荐 | 说明 |
|---|---|---|
| 按下缩放 + haptic | ✅ 已有 | 继续统一 |
| Tab indicator 滑动 | ✅ 已有 | 保持 |
| 数字滚动（Count-up） | ✅ 轻量 | 仅总资产 / 今日盈亏刷新时 200–300ms |
| 列表行分隔 / inset grouped | ✅ | 仿 iOS Settings / 持仓列表 |
| Sparkline（7 日迷你线） | ✅ 后期 | 持仓行右侧，SVG path，无库也可 |
| 配置环形图 / 条 | ✅ 分析 Tab | 单色环 + 图例，避免彩虹饼图 |
| 毛玻璃 Tab / Nav | ⚠️ 慎用 | PWA 上 `backdrop-filter` 贵且易糊；可用半透明实色代替 |
| 霓虹 glow / 紫渐变 | ❌ | 与金融冷静冲突，且触碰项目视觉禁区 |
| 大面积红底 | ❌ | Generali 改版明确：红只做语义，不做整页情绪 |

### 3.4 字体

保持系统栈（SF + PingFang）即可——金融 App 信任感来自系统字体，不必再引展示字体抢戏。**数字**可用 `SF Mono` / `ui-monospace` 仅作用于金额类 class。

## 4. 四 Tab：行业最佳信息架构 → 安崽落点

### 4.1 持仓（首页）— 对标 Delta / 持仓原型

**首屏预算（行业共识：3 秒扫完）：**

1. **英雄数字区**（非插画）：总市值 + 今日盈亏金额/%（红绿）  
2. **次级一行**：总成本 · 总浮盈 · 持仓只数（mute）  
3. **持仓列表**（主滚动）：名称/代码 | 市值 | 盈亏% | 现价  
4. **底**：免责声明（小、弱）

**行交互：** 点击 → 详情（后期）；长按 / 滑动 → 删除（你们已有 ActionSheet，保持）。  
**空态：** 大按钮「添加第一只 ETF」，示意代码 `510300`（已有雏形，强化 hero 即可）。

**不要：** 首页塞指数大盘、新闻、广告位、多段统计条。

### 4.2 市场 — 对标自选轻量，而非同花顺全站

个人助手的「市场」= **自选 / 关注池**，不是全市场。

| 模块 | 建议 |
|---|---|
| 顶 | 搜索加码（居中 Modal，字号 ≥16） |
| 列表 | 名称 · 最新价 · 涨跌幅（刷新点） |
| 可选 | 与持仓重合时显示「已持有」小标签 |

**不要：** 多指数横滑、板块热力图（除非以后明确要）。

### 4.3 分析 — 对标 Generali「结构清晰」+ 雪球「观点可读」

首页级分析报告结构（推荐固定模板，利于 Agent 复用）：

1. **一句话结论**（今日组合状态）  
2. **仓位结构**（条形或简单环：ETF / 个股 / 主题）  
3. **集中度 / 风险点**（最多 3 条 bullet）  
4. **可执行建议卡**（再平衡草案：加减哪只、目标占比）— **数字以后端为准**  
5. 免责声明

视觉：分析页用 **卡片分段**，每段一个标题 + 一句说明（符合「一节一事」）。

### 4.4 安崽（Agent）— 对标「结构化金融 Chat」而非纯 ChatGPT

最佳实现（开源/产品共识）：

| 元素 | 说明 |
|---|---|
| 建议提问 chips | 「今天亏在哪」「集中度如何」「给再平衡草案」 |
| SSE 流式字 | 打字感，底部输入固定在安全区上 |
| Tool 进度条/步骤 | `查持仓 → 拉行情 → 计算` 小状态点 |
| **结果卡** | 持仓摘要卡、调仓表、风险条 — 从 JSON 渲染，不靠 Markdown 表格硬撑 |
| 键盘 | 继续用居中输入区 / 底栏避让（已有规范） |

参考实现思路：Robinhood_AI_Portfolio_Analyzer（SSE + tool stages）、Advisor Desktop（action cards approve/reject）。

## 5. 实现技术选型（在现有栈内「最好」）

| 能力 | 推荐 | 不推荐（对个人项目过重） |
|---|---|---|
| 样式 | 继续 CSS 变量 + Tailwind 工具类 | 另起一套 UI kit 换肤 |
| 图表 | 轻量：**自写 SVG sparkline**；分析页可用 `recharts` 按需 | ECharts 全家桶先别上 |
| 列表虚拟化 | 持仓 <50 不必 | 过早虚拟列表 |
| 动效 | 见 [动效调研.md](./动效调研.md)：CSS 令牌 + reduced-motion | Framer Motion 全局化（不做） |
| 数据层 | 持仓轮询可维持；Agent/分析上 **React Query** | 现在就上复杂状态机 |
| 图标 | SF Symbol 风格 SVG / 简单线标 | emoji 当图标 |

## 6. 「最好 UI 效果」落地优先级（建议）

### P0 — 视觉与层级（投入小、观感跳一档）

1. 持仓页 **英雄数字区**（总市值 / 今日盈亏）  
2. 全局金额 class：`tabular-nums` + 涨跌 `↑↓`  
3. 列表统一 inset grouped（圆角分组 + separator）  
4. 刷新时总资产轻微 count-up 或 opacity pulse（≤300ms）

### P1 — 分析可读性

1. 分析页固定「结论 → 结构 → 建议卡」模板组件  
2. 简单仓位条（不必花饼图）

### P2 — Agent 质感

1. 建议 chips  
2. SSE + tool 步骤指示  
3. 调仓结果卡 / 持仓引用卡

### P3 — 锦上添花

1. 持仓行 sparkline  
2. 下拉刷新（真机）  
3. 可选极轻 blur Tab（性能验收后再开）

## 7. 反模式清单（调研中反复踩雷）

- 首页 stat 墙：4+ 指标卡并排 → 像后台，不像个人助手  
- 紫/霓虹/多阴影「AI 感」→ 廉价且违项目视觉规则  
- 交易按钮常驻（买入/卖出大按钮）→ 产品定位是分析助手  
- Agent 只有气泡没有卡片 → 金融建议难扫读、难核对数字  
- 图表默认红绿面积堆满 → 干扰涨跌语义色  
- 为「好看」破坏 safe-area / Tab 文档流（已有 iOS 文档约束）
