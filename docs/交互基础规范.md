## 2. 设计令牌（代码唯一来源：`globals.css` `:root`）

### 2.1 动效

权威调研与契约见 [动效调研.md](./动效调研.md)。

| 令牌 | 值 | 用途 |
|---|---|---|
| `--motion-fast` | 120ms | 按下、颜色、Tab |
| `--motion-base` | 180ms | 次级态、指示 |
| `--motion-enter` | 260ms | Modal / Sheet / Toast 入场 |
| `--motion-exit` | 200ms | 离场（快于入场） |
| `--motion-page` | 320ms | 罕用整页转场 |
| `--ease-enter` | `cubic-bezier(0.22, 1, 0.36, 1)` | 入场 |
| `--ease-exit` | `cubic-bezier(0.4, 0, 1, 1)` | 离场 |
| `--ease-standard` | `cubic-bezier(0.4, 0, 0.2, 1)` | 同元素两态 |
| `--ease-spring` | 轻微过冲 | **仅**按压；弹层禁用 |
| `--ease-out` | → `--ease-enter` | 旧别名 |
| `--press-scale` | 0.97 | 通用按下 |
| `--press-scale-strong` | 0.94 | 强反馈 |

规则：只动画 `opacity` / `transform`；根级 `prefers-reduced-motion`；时长用令牌不写魔法数字。

### 2.2 触控与安全

| 令牌 | 值 |
|---|---|
| `--hit-min` | 44px |
| `--sat/sab/sal/sar` | safe-area（底 floor 34px） |

### 2.3 反馈层级

1. **即时（&lt;50ms）**：按下缩放、颜色预亮、haptic  
2. **确认（100–220ms）**：选中态、指示条滑动、页面切入  
3. **结果（Toast）**：操作成功/失败文案  

禁止：无按下态的可点控件；无选中态的导航；用 `alert()`。

## 3. 组件约定

| 场景 | 用什么 |
|---|---|
| 主操作 | `.btn` + `haptics.tap()`（可选） |
| 次要/文字按钮 | `.btn-ghost` |
| 列表行可点 | `.row-pressable` 或 `Pressable` |
| 要打字的弹层 | **`CenterModal` 唯一**（底页冻 + 仅卡片随键盘上移） |
| 删除/菜单 | `ActionSheet` |
| 短结果 | `useOverlay().toast()` |
| 空列表 | `EmptyState` |
| 加载中 | `LoadingBlock` |
| 底栏 | 只通过 `TabBar`，勿复制 |

## 5. 前期 checklist（新功能上线前勾）

- [ ] 可点元素有按下反馈（缩放或背景）  
- [ ] 热区 ≥ 44px  
- [ ] 输入字号 ≥ 16px  
- [ ] 贴底/顶控件用了 safe 令牌  
- [ ] 成功/失败有 Toast，不用 alert  
- [ ] 有输入用 CenterModal，无输入用 Sheet（禁止自研 portal 弹层）  
- [ ] 弹窗×键盘：底页不动、仅卡片上移（[弹窗键盘规范.md](./弹窗键盘规范.md) §4）  
- [ ] 动效时长来自令牌，不写魔法数字  
- [ ] 真机或窄屏下看过一遍
