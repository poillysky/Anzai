## 1. 「2笔」是什么？减仓会不会变成两笔？

| 操作 | 数据库 | 列表展示 |
|---|---|---|
| **添加持仓**（点 +） | `INSERT` 一条 `Holding` | 同代码多条 → 合并成一卡，角标「N笔」 |
| **补仓**（详情里） | `UPDATE` **同一条** 的份额+加权成本 | 仍 1 笔 |
| **减仓**（详情里） | `UPDATE` **同一条** 只减份额，**成本价不变** | 仍 1 笔 |
| **空仓** | `DELETE` 该条 | 消失 |

**结论：减仓绝不会拆成两笔。**  
看到「2笔」= 这只股票被 **添加了两次**（或历史遗留两条记录），不是减仓造成的。

正确加仓路径：点已有持仓 → **补仓**。  
「+ 添加」仅用于仓库里还没有的代码；若代码已存在，产品应并入补仓（见实现）。

## 2. 业界常见成本口径（调研摘要）

券商 APP 常见几类（名称因券商而异）：

| 模式 | 补仓 | 部分卖出（减仓） | 说明 |
|---|---|---|---|
| **买入均价 / 持仓成本（不计卖出）** | 加权平均成本 | **剩余持仓单位成本不变**；卖出盈亏视为已实现 | 直观；本站采用 |
| **摊薄持仓成本** | 加权 | 卖出盈亏摊回剩余持仓，单位成本会变，甚至可为负 | 同花顺等常见「摊薄」 |
| **保本价等** | 含预估卖出费用 | — | 偏交易决策，本站不做 |

参考：移动加权买入合并成本；部分卖出是否改成本因「模式」而异；清仓后成本归零，再买重新起算。页面成本仅为复盘参考，精确以交割单为准。手续费/印花税本站暂不计入。

## 3. 本站锁定口径（个人仓管）

### 3.1 单条持仓字段

| 字段 | 含义 | 公式 |
|---|---|---|
| `cost` | 单位成本（买入均价） | 见补/减仓 |
| `shares` | 当前份额 | — |
| `last_price` | 最新价 | 行情 |
| `market_value` | 市值 | `shares × last_price` |
| `pnl` | **持仓浮动盈亏** | `market_value − shares × cost` |
| `pnl_pct` | 累计盈亏% | `pnl / (shares × cost) × 100` |
| `day_pnl` | **今日盈亏** | `shares × (last_price − prev_close)`；**上海日历跨日**后若行情 `as_of` 仍是昨天，记 **0**（不用昨盘涨跌冒充今日） |
| `change_pct` | 当日涨跌幅 | 行情相对昨收；同上，跨日且 `as_of` 非今日时按 **0** 展示 |
| `weight` | 仓位占比 | `market_value / Σ market_value × 100` |

组合层：`total_*` / `day_pnl` 为各持仓加总（今日盈亏%用昨收市值加权）。

### 3.2 补仓（加权平均）

\[
cost' = \frac{shares \times cost + qty \times price}{shares + qty},\quad shares' = shares + qty
\]

### 3.3 减仓（成本不变）

\[
shares' = shares - qty,\quad cost' = cost
\]

- 已实现盈亏（本站暂不单独记账展示）≈ `qty × (卖出价 − cost)`，用户可在交割意识里自行理解。  
- 减至 0 → 空仓删除该条。  
- **不**采用「摊薄成本」改 `cost`。

### 3.4 同代码唯一一行

库表与 UI：**每个 `(市场, 代码)` 只有一条持仓**。  
加载 / 添加时服务端自动加权合并多余行。减仓改的是这条上的总份额，列表数字与详情一致。

## 4. 场景速查

| 场景 | 份额 | 成本 | 浮动盈亏 | 今日盈亏 |
|---|---|---|---|---|
| 首次买入 1000@4.0 | 1000 | 4.0 | 市值−4000 | 相对昨收 |
| 补仓 500@3.0 | 1500 | 3.667 | 相对新成本 | 全仓×涨跌 |
| 减仓 500（剩 1000） | 1000 | **仍 3.667** | 相对原成本 | 剩仓×涨跌 |
| 空仓 | 删除 | — | — | — |
| 误「添加」同代码第二次 | 两条记录 | 各记各的 | 列表合并加总 | 合并加总 |

## 5. 日 / 月 / 年收益汇总（仓库英雄区）

入口：安崽老婆本下「今日」一行 → `CenterModal`「收益日历」（支付宝式周历格子）。

| 维度 | 展示 |
|---|---|
| **日** | 当月 7 列日历：日一二…六；格内日期 + 盈亏（红涨绿跌） |
| **月 / 年** | 当年 3×4 月格 |
| **¥ / %** | 格子显示金额或涨跌幅 |

| 来源 | 说明 |
|---|---|
| **live** | 打开仓库 / 收益日历时写入**当日**实时 `day_pnl` |
| **bought** | 按持仓 `bought_at`（买入日，默认当日）起，用**当前份额 × 日 K** 回补历史日；与 live 同日时以 live 为准 |

持仓字段 `bought_at`（`YYYY-MM-DD`）：添加时默认今天；详情「改成本」可改。旧仓迁移用 `created_at` 日期填充。

API：`GET /api/holdings/returns?dim=day\|month\|year&ref=YYYY-MM-DD`  
代码：`app/services/portfolio_returns.py` · `holding_dates.py` · `PortfolioScreen`。

**仍非**完整已实现盈亏流水（卖出归档、出入金校正未做）；回补不含历史调仓过程。
