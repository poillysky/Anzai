## 0. 业界结论（先定公式再写码）

### 0.1 两个指标必须分列

| 指标 | 回答的问题 | 成熟软件口径 |
|---|---|---|
| **浮动 / 持仓盈亏** | 相对我的成本，现在赚亏多少？ | `(现价 − 成本) × 现仓` |
| **今日 / 当日盈亏** | 相对昨天收盘（加今天买卖），今天赚亏多少？ | 见下节现金流转公式 |

混用「相对昨收」去算当日新买入，会把昨收涨跌算进你的今日盈亏 → 失真。

### 0.2 今日盈亏（券商主流）

长桥 / 老虎 / 东莞证券等价公式：

\[
\text{当日盈亏}
= \text{现价}\times\text{现仓}
- \text{昨收}\times\text{日初仓}
+ \text{当日卖出成交额}
- \text{当日买入成交额}
\]

老虎今日盈亏% 分母 ≈ **昨收×日初仓 + 当日买入成交额**。

| 场景 | 公式怎么自然覆盖 |
|---|---|
| 隔夜持有、今日未交易 | \(现价\times仓 − 昨收\times仓\) |
| **当日首次买入** | 日初仓=0 → \(现市值 − 买入额\)（相对买入价） |
| 昨仓 + 今补 | 昨仓对昨收，今买额从公式里减掉 |
| **今卖部分** | +卖出额，现仓变少 → 含已实现 |
| 今做 T（先卖后买） | 卖出额、买入额同时进入 |
| 跨日未开盘 / 行情仍是昨收 | 今日盈亏记 **0**（上海日历） |

手续费：成熟 App 多数「当日盈亏」不含佣金（长桥注）；本站亦不计。

### 0.3 成本（本站锁定）

| 模式 | 补仓 | 减仓 | 本站 |
|---|---|---|---|
| **买入均价** | 加权 | **成本不变**，卖出视为已实现 | ✅ 采用 |
| 摊薄成本 | 加权 | 卖出盈亏摊回剩余成本 | ❌ 不做 |
| 含费保本价 | — | — | ❌ 不做 |

IB / Alpaca：浮动盈亏用平均成本；Daily P&L 用昨收到今日 + 新开仓（与上节同构）。

### 0.4 本站实现字段

| 字段 | 作用 |
|---|---|
| `cost` / `shares` | 买入均价持仓 |
| `sod_shares` + `sod_asof` | 上海日历日初仓；跨日按现仓快照重置 |
| `day_buy_amount` / `day_sell_amount` | 当日买入/卖出成交额累计 |
| `day_buy_shares` / `day_buy_cost` | 今买份额镜像（展示/兼容）；跨日清零 |
| `bought_at` | 首次买入日（收益日历回补起点） |

补/减仓 API 传 `trade_price`（成交价），写入今买/今卖额。

## 1. 「2笔」是什么？减仓会不会变成两笔？

| 操作 | 数据库 | 列表展示 |
|---|---|---|
| **添加持仓**（点 +） | 无则 INSERT；有则并入补仓 | 同代码 **1 行** |
| **补仓** | UPDATE 份额+加权成本 + 记今买额 | 仍 1 笔 |
| **减仓** | UPDATE 只减份额，成本不变 + 记今卖额 | 仍 1 笔 |
| **空仓** | DELETE | 消失 |

**减仓绝不会拆成两笔。** 「2笔」只可能是历史重复行（加载时服务端合并）。

## 2. 本站字段与公式

| 字段 | 含义 | 公式 |
|---|---|---|
| `cost` | 买入均价 | 见补/减仓 |
| `market_value` | 市值 | `shares × last` |
| `pnl` | 浮动盈亏 | `market_value − shares × cost` |
| `pnl_pct` | 累计% | `pnl / (shares × cost) × 100` |
| `day_pnl` | **今日盈亏** | `last×shares − 昨收×sod + day_sell_amount − day_buy_amount`；行情跨日陈旧 → **0** |
| `day_pnl_pct` | 今日% | `day_pnl / (昨收×sod + day_buy_amount)` |
| `change_pct` | 行情涨跌幅 | 相对昨收（行情口径） |
| `weight` | 仓位占比 | `market_value / Σ mv × 100` |

## 3. 补仓 / 减仓

**补仓（加权）**

\[
cost' = \frac{shares \times cost + qty \times price}{shares + qty},\quad shares' = shares + qty
\]

同时：`day_buy_amount += qty × price`（买入日=上海今日时）。

**减仓（成本不变）**

\[
shares' = shares - qty,\quad cost' = cost
\]

同时：`day_sell_amount += qty × trade_price`。

减至 0 → 删除行。（当日清仓后再买：新行日初仓=0；清仓那笔已实现若行已删则不再挂在组合上——个人仓管可接受；完整交割流水属延期项。）

## 4. 场景矩阵（验收用）

设昨收 \(P_0\)，现价 \(P\)。

| # | 场景 | 日初仓 | 今买额 | 今卖额 | 现仓 | 今日盈亏 | 浮动盈亏 |
|---|---|---|---|---|---|---|---|
| A | 隔夜 1000，未交易 | 1000 | 0 | 0 | 1000 | \(1000(P-P_0)\) | 相对成本 |
| B | **当日首买** 1000@C | 0 | \(1000C\) | 0 | 1000 | \(1000(P-C)\) | \(1000(P-C)\) |
| B2 | **昨买今录** 1000@C（买入日=昨天） | 1000 | 0 | 0 | 1000 | \(1000(P-P_0)\) | \(1000(P-C)\) |
| C | 昨 1000 + **今补** 500@C | 1000 | \(500C\) | 0 | 1500 | \(1500P - 1000P_0 - 500C\) | 相对加权成本 |
| C2 | 已有昨仓 + **补录昨买** 500@C | 1500 | 0 | 0 | 1500 | \(1500(P-P_0)\) | 相对加权成本 |
| D | 今买两笔（同日） | 0 | 两笔之和 | 0 | 合计 | \(现市值 − 今买额\) | 相对加权成本 |
| E | 昨 1000，**今卖** 300@S | 1000 | 0 | \(300S\) | 700 | \(700P - 1000P_0 + 300S\) | 剩仓×成本 |
| F | 昨 1000，先卖 50@S 再买 50@C | 1000 | \(50C\) | \(50S\) | 1000 | \(1000P - 1000P_0 + 50S - 50C\) | 相对成本 |
| G | 跨日、行情 as_of 仍昨天 | — | — | — | — | **0** | 仍算浮动 |
| H | 仅改成本、份额不变 | 不变 | 不变 | 不变 | 不变 | 今日不变 | 浮动变 |

### 4.1 同股多日多笔怎么汇总（本站）

库表仍 **一行一代码**（加权成本 + 最早 `bought_at`），不拆多行。今日盈亏靠：

| 字段 | 含义 |
|---|---|
| `sod_shares` | 今天开盘前已持有的份额（含所有「买入日早于今天」的补录） |
| `day_buy_amount` | 今天成交的买入额合计 |
| `day_sell_amount` | 今天成交的卖出额合计 |

\[
\text{今日盈亏}=P\times\text{现仓}-P_0\times\text{日初仓}+\text{今卖额}-\text{今买额}
\]

\[
\text{浮动盈亏}=(P-\text{加权成本})\times\text{现仓}
\]

录入规则：

1. **添加 / 补仓**必须填 **买入日 + 买入价**  
2. 买入日=今天 → 进今买额（今日盈亏相对成交价）  
3. 买入日早于今天 → 进日初仓（今日盈亏相对昨收；累计仍相对你的买入价）  
4. 同代码再买 → 并入同一行，成本加权，日初/今买按上面 2/3 拆

数值自检（长桥案例 2）：\(P_0=190,P=200\)，卖 50@202，买 50@198 →  
\(200\times100 - 190\times100 + 10100 - 9900 = 1200\)。

## 7. 复盘：公式漏洞与对策（2026-08-06）

| 漏洞 | 后果 | 对策 |
|---|---|---|
| 日初仓未初始化（sod=0 且无今买额） | 今日盈亏≈市值、+100% | `ensure` 补快照；`day_pnl_cashflow` 兜底改按昨收 |
| **先改份额再滚日** | 今买被算进日初仓，今日盈亏算反 | 路由在改仓前 `ensure`；`record_*` 兜底用 `shares∓qty` |
| `baseline≤0` 时用涨跌幅覆盖 | 覆盖正确现金流转结果 | 仅在无买无卖时才回退涨跌幅 |
| 用 `day_buy_asof` 当已滚日 | SOD 永不写入 | 只认 `sod_asof` |
| 减仓不传成交价 | 今卖额用成本低估 | API `trade_price`；前端减仓带卖出价 |
| 空仓 DELETE | 当日已实现从组合消失 | 产品接受；完整流水延期 |
| 仅改成本、份额不变 | 不应动今日盈亏 | `delta=0` 不记买卖 |
| 跨日行情 as_of 仍昨天 | 冒充今日涨跌 | `fresh_today` 时 day_pnl=0 |

验收脚本：`apps/api/scripts/verify-day-pnl.py`（场景 A/B/C/E/F + 滚日顺序 + heal）。

**已再修（前端细节）**：删除后汇总用 `day_pnl_pct` 反推分母；停用客户端合并重复仓（避免误记今买）；减仓必填卖出价；详情「今日盈亏」带比例，行情涨跌幅标「行情」。

**仍延期**：空仓 DELETE 不保留当日已实现；收益日历历史回补非现金流转；Agent/分析里个股「今日」仍可能写行情涨跌幅。

## 8. 一页对照卡（vs 长桥 / 老虎 / 东莞）

### 8.1 总公式

| 指标 | 公式 |
|---|---|
| 浮动盈亏 | \((P-C)\times Q\) |
| 浮动% | 浮动 / \((C\times Q)\) |
| **今日盈亏** | \(P\times Q_{\text{现}}-P_0\times Q_{\text{日初}}+\text{今卖额}-\text{今买额}\) |
| 今日% | 今日 / \((P_0\times Q_{\text{日初}}+\text{今买额})\)（老虎分母） |
| 行情涨跌幅 | 相对昨收 —— **≠** 今日盈亏% |

### 8.2 成本

| 操作 | 成本 | 今日字段 |
|---|---|---|
| 补仓 @\(C_b\) | 加权 | 买入日=今天 → 今买额；更早 → 日初仓 |
| 减仓 @\(S\) | **不变** | 今卖额 \(+=qS\) |
| 只改成本 | 变 | 今日不动 |

### 8.3 场景速查

| # | 场景 | 今日 | 浮动 |
|---|---|---|---|
| A | 隔夜未交易 | \(Q(P-P_0)\) | \(Q(P-C)\) |
| B | 当日首买 \(Q@C\) | \(Q(P-C)\) | \(Q(P-C)\) |
| B2 | 昨买今录 | \(Q(P-P_0)\) | \(Q(P-C)\) |
| C | 昨仓 + 今补 | \((Q_0+q)P-Q_0P_0-qC_b\) | 加权成本 |
| C2 | 昨仓 + 补录昨买 | \((Q_0+q)(P-P_0)\) | 加权成本 |
| D | 同日多笔买 | 现市值 − 今买额 | 加权成本 |
| E | 今卖部分 | \((Q-q)P-QP_0+qS\) | 剩仓×成本 |
| F | 做 T（先卖后买） | \(QP-QP_0+qS-qC_b\) | 相对成本 |
| G | 行情跨日陈旧 | **0** | 仍算浮动 |
| H | 只改成本 | 今日不变 | 浮动变 |

长桥自检：\(P_0=190,P=200\)，卖 50@202、买 50@198 → 今日 **1200**。

### 8.4 对齐结论

| 项 | 结论 |
|---|---|
| 今日现金流转 / 今日% 分母 / 买入均价 / 减仓成本不变 / 今买相对成交价 / 不计佣金 | **对齐** |
| 摊薄成本、清仓后挂当日已实现、公司行为调成本、完整交割流水 | **不做 / 延期** |

### 8.5 录入口诀

1. 买入日=今天 → 今买额 → 今日对买入价  
2. 买入日更早 → 日初仓 → 今日对昨收；累计仍对买入价  
3. 减仓必填卖出价  
4. 「行情」涨跌幅不要当成今日盈亏%
