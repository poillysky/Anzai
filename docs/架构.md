## 分层约定（强制）

> Cursor 规则：`.cursor/rules/architecture.mdc`（始终生效）。

### 新代码权威路径

| 用途 | 写这里 | 不要写这里 |
|---|---|---|
| 配置 / 鉴权 | `app/core/` | `config.py` / `auth.py` |
| DB 会话 | `app/database/` | `db.py` |
| HTTP 路由 | `app/api/routes/` | `app/routers/`（仅 shim） |
| 行情适配 | `app/providers/` | 在 `services/quote.py` 加实现 |
| 业务屏 | `src/features/<域>/` | 在 `app/**/page.tsx` 堆 UI |
| HTTP 调用 | `@/lib/api` | 页面内直接 `fetch` |

旧 shim（`config.py` / `auth.py` / `db.py` / `routers/` / `services/quote.py`）**只保留 re-export，禁止扩逻辑、禁止新增 shim 文件**。全仓无引用后再删。

### 前端

1. **`app/`** 只做路由与 metadata，业务 UI 放进 **`features/*/…Screen.tsx`**。
2. **组件三层**：`layout`（壳）/ `overlay`（遮罩）/ `ui`（原子）。
3. **所有 HTTP** 经 `@/lib/api`。
4. **providers** 包住 AppShell；QueryClient 挂这里（见下表触发条件）。

### 后端

1. **`core`**：配置与鉴权，无业务。
2. **`database`**：SQLAlchemy 会话；模型暂在 `models.py`。
3. **`api/routes`**：HTTP 边界；`get_db` / `require_password`。
4. **`services`**：领域逻辑；外部 IO 走 **`providers`**。

### 网络

- 浏览器 → Next `3515` → rewrite `/backend` → FastAPI `8515`
- 公网：`https://anzai.605081.xyz:16666` → 反代到 `3515`
- **管理后台**：仅 API 直连 `http://127.0.0.1:8515/admin`（登录后分页：`/admin/accounts` · `/admin/llm` · `/admin/presets` · `/admin/agent`）。**L0 模型连接**（`/admin/llm` + `data/llm_profiles.json` + `.env` 的 `LLM_*`）与 **L1 对话预设**（`/admin/presets` + `data/llm_presets.json`：人设 / 口吻 / 采样 top_p·惩罚 / 历史轮数 / 开场 chips，学 BrewStory 预设「设置」但面向**真人对话**，不含密钥与 ST 提示词链）分开展示落盘。Next rewrite **不**代理 `/admin`，PWA 内不开放入口。

## 延期事项（触发再做）

| 事项 | 何时做 | 怎么挂 |
|---|---|---|
| **React Query** | 开始做 **Agent** 或 **分析**（缓存 / 重试 / 失效有痛点） | `@tanstack/react-query` + `AppProviders` |
| **测试** | 组合计算、行情解析、Agent tool 等易回归逻辑出现时 | API：`pytest`；前端：按需单测，不追求全覆盖 |
| 共享类型 / OpenAPI | 前后端字段经常对不齐时 | 再考虑 `packages/shared` 或生成客户端 |
| 删 shim | 确认无 import 后 | 一次删干净，勿半删 |

个人项目原则：**先填业务，不空转完善地基。**
